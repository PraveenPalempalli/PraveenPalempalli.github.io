## Security

Static site only; no backend, forms, credentials, third-party scripts, tracking or external runtime dependencies. HTML Content Security Policy restricts executable scripts to this origin and the exact structured-data block, blocks network connections, forms, embedded content and plugins. HTTPS is enforced through GitHub Pages settings. GitHub Pages controls HTTP response headers; the HTML policy cannot supply frame-ancestors or other response-header-only protections. Account security depends on the owner protecting authentication and recovery methods.
